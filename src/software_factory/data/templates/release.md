# Release evidence

This record describes an existing authorized delivery process. It does not execute a deployment or supply approval.

## Candidate

Record mission IDs, actual merged revision, artifact digest and build provenance/reference. Use the same artifact identity through staging and promotion.

## Staging

Identify target environment, pipeline run, actual deployed artifact, executed checks and results. Include independent acceptance evidence when configured.

## Release decision

Reference the actual decision for this artifact, target and recovery plan. Record who/what issued it and when. Revalidate if the subject changes.

## Promotion and observation

Record deployment operation ID, actual target artifact, health/user-flow observations and completion criteria. Separate attempted, in-progress and verified delivery.

## Recovery

Link the recovery record and configured trigger/action, including code/data implications. Describe unresolved risks and follow-up work.
